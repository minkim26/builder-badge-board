# AWS Weekend Deployment Challenge — Rules Reference

This doc exists purely for reference when writing the eventual Builder Center
article. It should not influence code structure — see `PRD.md` and
`ARCHITECTURE.md` for that.

## Timeline

- Opens: September 11, 12:00 AM PT
- Closes: September 14, 1:00 PM PT

## Requirements

1. Build and deploy a real, working app on at least one AWS service.
2. Publish an article on AWS Builder Center:
   - Title format: `Weekend Deployment Challenge: [Name of Your App]`
   - Tagged `#deployment`
   - 500+ words
   - Published within the challenge window
3. Article must cover:
   - What the app does
   - How it was built (process, decisions, challenges)
   - AWS services used + architecture overview (diagrams encouraged)
   - What was learned
   - A working link to the app or a public GitHub repo

## Evaluation

Pass/fail, judged on:
- Completeness
- Relevance / functionality
- AWS service usage

## Rewards

- First 100 passing submissions get $100 in AWS credits, on top of the $200
  free-tier credit new accounts already get for Bedrock/Nova/Amplify/Lambda/etc.

## AWS's own tip

Deploy early (Saturday), write the article once it's working (Sunday).
